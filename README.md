## 📋 Sobre o Projeto

Repositório dedicado ao desenvolvimento de projetos web front-end, explorando desde conceitos básicos até técnicas avançadas de desenvolvimento. Este portfólio demonstra habilidades em **HTML5**, **CSS3**, **JavaScript** e **Tailwind CSS** através de projetos práticos, funcionais e com design focado na experiência do usuário (UI/UX).

### ✨ Características Principais

- 🎨 **Design Moderno** - Interfaces limpas com foco em UI/UX e padrões de mercado (Glassmorphism, Mockups).
- 🌙 **Modo Escuro/Claro** - Tema automático baseado na preferência do usuário.
- ⚡ **Performance Otimizada** - Carregamento rápido, sem dependências pesadas e código limpo.
- ♿ **Acessibilidade** - Seguindo padrões WCAG e HTML semântico.
- 🔧 **Código Limpo** - Estrutura organizada, componentizada e bem documentada.

## 🎨 Projetos em Destaque

### 1. 🌤️ Aplicativo de Clima (ClimaTempo)
[![Demo](https://img.shields.io/badge/Demo-Live-success?style=flat-square)](https://clima-eta-two.vercel.app/)

**Aplicação completa para consultar condições climáticas em tempo real.**

- **Funcionalidades:** Busca por cidade ou seleção via continentes, exibição de temperatura e umidade, ícones dinâmicos, previsão estendida (5 dias) e imagens de fundo via API.
- **Destaque Técnico:** Interface imersiva com *Glassmorphism*, gerenciamento de estado complexo em cascata (continente > cidade) e tratamento de erros de requisições assíncronas.
- **APIs:** OpenWeatherMap, Unsplash, FlagsAPI.

### 2. 📚 Estante Virtual
[![Demo](https://img.shields.io/badge/Demo-Live-success?style=flat-square)](https://projeto-estante.vercel.app/)

**Sistema de curadoria literária com leitor interativo.**

- **Funcionalidades:** Acervo com 39 obras e 37 resenhas, leitor dinâmico de metadados, filtros e categorização.
- **Destaque Técnico:** Arquitetura de dados estruturados (JSON) e renderização condicional de conteúdo sem recarregamento de página.

### 3. 🎵 Biografia Scarlxrd
[![Demo](https://img.shields.io/badge/Demo-Live-success?style=flat-square)](https://biografia-scarlxrd.vercel.app/)

**Página biográfica com storytelling visual e linha do tempo.**

- **Funcionalidades:** Timeline da carreira do artista, discografia, estatísticas e design temático.
- **Destaque Técnico:** Foco em arquitetura de informação, HTML semântico (SEO) e layout editorial otimizado para leitura de grandes blocos de texto.

## 🚀 Como Executar Localmente

### Pré-requisitos
- Navegador web moderno
- Servidor local (opcional, mas recomendado)

### Instalação

1. **Clone o repositório**
   ```bash
   git clone https://github.com/brianmunizsilveira/repositorio.git
   cd repositorio
   ```

2. **Execute um servidor local**
   ```bash
   # Usando Python 3
   python -m http.server 8000
   
   # Usando Node.js (npx)
   npx serve .
   
   # Usando PHP
   php -S localhost:8000
   ```

3. **Acesse no navegador**
   ```
   http://localhost:8000
   ```

## 🤝 Como Contribuir

Contribuições são sempre bem-vindas! Siga os passos abaixo:

1. **Fork o projeto**
2. **Crie uma branch para sua feature**
   ```bash
   git checkout -b feature/nova-funcionalidade
   ```
3. **Commit suas mudanças**
   ```bash
   git commit -m 'Adiciona nova funcionalidade'
   ```
4. **Push para a branch**
   ```bash
   git push origin feature/nova-funcionalidade
   ```
5. **Abra um Pull Request**

### 📝 Diretrizes de Contribuição
- Mantenha o código limpo e bem documentado.
- Siga os padrões de acessibilidade.
- Teste em diferentes navegadores e garanta a responsividade.
